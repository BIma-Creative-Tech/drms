# RR Teams 0.14.0

- **Instruksi pinjam antar proyek (Owner):** bila dana bebas akun kas proyek tidak cukup, Setujui nonaktif. Pilih proyek pemberi pinjaman di PT yang sama (dengan dana bebas akun kasnya), isi nominal dan alasan.
- Pinjaman langsung masuk Antrian Transfer Finance. Setelah Finance mentransfer, Anda mendapat notifikasi dan pengajuan bisa disetujui.
- **Absensi Non-OnSite:** bisa absen masuk/pulang di mana saja. Di luar lokasi terdaftar, absen dicatat "Di luar area" pada lokasi terdekat.
- **Rekap bulanan tim:** Owner, Direktur, Admin, Finance, Admin Staff dan PM langsung melihat rekap tim per karyawan (pilih bulan, PT, cari nama). PM bisa beralih Tim / Saya.
- Pesan error dari server (mis. akun belum terhubung ke data karyawan) kini langsung tampil, tanpa loading lama.
- Butuh server RR Teams versi 0.22.0.
