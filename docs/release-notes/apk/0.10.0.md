# RR Teams 0.10.0

- **Semua menu web sekarang ada di aplikasi.** Menu bertanda "Segera hadir di APK" sudah tidak ada.
- **Proyek:** Klien (dengan kontak PIC), Pusat biaya, Penugasan tim, Tahapan, Jenis tenaga/alat/servis, RAB dan Kontrak unit — lihat, tambah, ubah, hapus atau nonaktifkan sesuai hak Anda.
- **Kelola RAP** (tab RAP proyek): tambah dan ubah item, impor file Excel dari HP, unduh template atau RAP (.xlsx), dan pakai template RAP.
- **Unit & kontrak:** status timesheet hari ini, total bulan ini, daftar unit, dan tombol "Isi timesheet".
- **Absensi:** Jadwal & hari libur — jadwal kerja, jadwal default PT, hari libur per tahun, lokasi absen (buka di peta) dan jadwal per karyawan.
- **Pengguna & Akses (Admin):** matriks Akses PT, Pengguna baru (akun, peran per PT, karyawan, rekening, penugasan; kata sandi sementara ditampilkan sekali), dan Cabut perangkat.
- **Master Data, Media, Pengaturan, Sistem:** Bank, Satuan, Kendaraan, Vendor (dengan rekening), Site, foto dan lampiran (pratinjau gambar), PT, Penomoran, Setting aplikasi, dan Audit Log.
- Perubahan yang wajib beralasan (misalnya menonaktifkan data) meminta alasan, sama seperti di web.
- Butuh server RR Teams versi 0.18.0.
