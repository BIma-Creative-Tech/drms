# ProyekKas 0.2.0

- Tampilan baru, selaras dengan ProyekKas versi web: warna, huruf, dan ikon yang sama.
- Mode gelap dan terang: pilih di Profil → Tampilan (Sistem, Terang, atau Gelap).
- Beranda kini berupa menu ubin berwarna, sehingga semua menu terlihat tanpa perlu menggulir.
- Jumlah yang menunggu (misalnya persetujuan) tampil langsung di ubin menu.
- Menu bawah dengan ikon baru yang lebih jelas.
- Tulisan dan tombol tetap besar agar mudah dipakai di lapangan.
- Cara kerja aplikasi tidak berubah: pengajuan, absensi, dan laporan progress tetap seperti biasa.
