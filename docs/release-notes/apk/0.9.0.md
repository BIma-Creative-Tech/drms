# RR Teams 0.9.0

- **Menu sama dengan web:** Beranda sekarang berisi menu modul seperti di web. Ketuk satu menu untuk membuka isinya. Menu yang belum ada di aplikasi tampil abu-abu dengan tulisan "Segera hadir di APK".
- **Dashboard** punya tab sendiri. Bila Anda punya lebih dari satu peran, tiap peran tampil di tab masing-masing.
- **Menu bawah menyesuaikan peran Anda** (Staff, PM, Direktur, Finance, Owner, Admin, Operator). Antrean sinkron sekarang ada di Profil.
- **Profil & tanda tangan:** lihat data profil, lalu gambar tanda tangan di layar, ambil dari galeri, atau hapus.
- **Keamanan akun:** lihat status 2FA. Untuk mengaktifkan atau mengelola 2FA, aplikasi membuka halaman web.
- **Keuangan (Finance dan Direktur):** Buku kas, Kas masuk/keluar, Tutup buku, Void transfer, Pinjaman antar project dan antar-PT, serta daftar data keuangan, langsung di aplikasi.
- **Laporan:** buka laporan sesuai peran, atur filter, lalu ekspor ke CSV, Excel, atau PDF. File bisa dibuka, dibagikan (WhatsApp, email, Drive), atau disimpan ke folder Download/ProyekKas.
- Butuh server RR Teams versi 0.17.0.
