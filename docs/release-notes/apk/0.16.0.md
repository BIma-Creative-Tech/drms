# RR Teams 0.16.0

- **Laporan Service: foto dari galeri.** Tombol + pada Foto sebelum / sesudah kini menawarkan "Ambil dari kamera" atau "Pilih dari galeri"; dari galeri bisa memilih beberapa foto sekaligus.
- Batas tetap 25 foto per laporan; bila memilih lebih dari sisa kuota, hanya foto yang muat yang ditambahkan dan aplikasi memberi tahu.
- **Pengguna: Reset kata sandi.** Admin dapat membuat kata sandi sementara baru untuk pengguna yang lupa kata sandi (Pengguna › akun › Akun › Reset kata sandi); pengguna wajib menggantinya saat login berikutnya.
