# RR Teams 0.11.0

- **Pusat biaya = akun kas.** Pengajuan tidak lagi memilih pusat biaya; detail pengajuan dan project menampilkan pusat biaya (akun kas) project.
- **Transfer (Finance):** *Dibayar dari akun* otomatis berisi pusat biaya project. Bila memilih akun lain, isi alasannya — tercatat otomatis sebagai pinjaman antar project (kas keluar dari akun pembayar, kas masuk ke pusat biaya project). Project yang belum dipetakan tidak bisa ditransfer.
- **Pinjaman antar project:** tombol **Cairkan** (Finance) untuk pinjaman dana antar pusat biaya berbeda; pengembalian menampilkan nomor kas keluar / kas masuk. Pinjaman otomatis dari transfer menampilkan akun pemberi.
- **Pembayaran vendor / antar-PT** boleh tanpa project (langsung ke Direktur).
- Butuh server RR Teams versi 0.19.0.
