# RR Teams 0.4.0

- Menu baru **Laporan Lapangan** di Beranda untuk project kontrak unit dan aftersales. Isinya mengikuti jenis project yang ditugaskan ke Anda.
- **Laporan Servis Unit**: pilih unit (cari kode unit atau plat), isi HM, keluhan, tindakan, sparepart yang dipakai, status unit setelah servis, dan foto sebelum/sesudah.
- **Timesheet Unit** harian per unit kontrak: HM awal terisi otomatis dari HM akhir sebelumnya, foto meter HM wajib, jam kerja/standby/breakdown maksimal 24 jam, dan tombol "Salin dari kemarin".
- **Aktivitas Aftersales**: catat penawaran, PO masuk, pengiriman (pilih PO terbuka pelanggan), penagihan, dan kunjungan, lengkap dengan foto surat jalan.
- Semua laporan lapangan bisa dibuat tanpa sinyal: tersimpan sebagai draft di HP dan terkirim otomatis saat ada sinyal. Statusnya terlihat di "Riwayat saya".
- Laporan bisa diubah sendiri sampai 24 jam setelah terkirim; sesudahnya minta koreksi PM/Direktur.
- Termasuk semua perubahan versi 0.3.6 (tingkat urgensi, peran Operator/Anggota, absensi untuk semua peran).
- Butuh server RR Teams versi 0.7.0 dan fitur "Laporan lapangan" diaktifkan Admin/Direktur untuk PT Anda. Bila belum aktif, menu ini tidak tampil.
