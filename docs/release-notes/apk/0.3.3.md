# ProyekKas 0.3.3

- Baru: "Pemberitahuan privasi" — menjelaskan data apa yang dicatat aplikasi (termasuk selfie dan lokasi saat absen), untuk apa, siapa yang bisa melihat, dan berapa lama disimpan.
- Setelah masuk, pemberitahuan ini tampil sampai Anda membacanya dan menekan "Saya mengerti".
- Absensi (absen masuk/pulang, selfie, dan absen oleh PM) baru bisa dipakai setelah Anda menekan "Saya mengerti". Fitur lain tetap bisa dipakai.
- Bila Anda memilih "Nanti", pemberitahuan muncul lagi saat aplikasi dibuka berikutnya.
- Tanpa sinyal: "Saya mengerti" dikirim otomatis saat online kembali. Sampai terkirim, absensi tetap terkunci.
- Baca kembali kapan saja di Profil → Pemberitahuan privasi.
