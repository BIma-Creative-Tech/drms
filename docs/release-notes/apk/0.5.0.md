# RR Teams 0.5.0

- **Laporan Harian** untuk project konstruksi di menu Laporan Lapangan: cuaca pagi/siang/sore, jam hujan dan jam kerja berhenti, volume pekerjaan hari ini per item RAP, material masuk/terpakai, jumlah tenaga per jenis, alat (unit dan jam kerja), kendala, catatan, dan sampai 10 foto.
- Item pekerjaan dikelompokkan per tahapan dan menampilkan realisasi dibanding volume RAP. Bila volume melebihi RAP, aplikasi memberi tanda dan catatan wajib diisi; laporan tetap terkirim dan PM project diberi notifikasi.
- Satu laporan harian per project per hari. Bila sudah ada laporan Anda untuk tanggal itu di HP, aplikasi menawarkan membuka laporan tersebut.
- Bisa dibuat tanpa sinyal: tersimpan sebagai draft di HP dan terkirim otomatis saat ada sinyal. Item RAP dan jenis tenaga/alat disimpan di HP setiap kali menu dibuka saat online (tanpa harga).
- Laporan bisa diubah sendiri sampai 24 jam setelah terkirim; sesudahnya minta koreksi PM/Direktur.
- Butuh server RR Teams versi 0.8.0 (RAP + Laporan Harian) dan fitur "Laporan lapangan" aktif untuk PT Anda. Untuk project selain konstruksi tidak ada perubahan.
