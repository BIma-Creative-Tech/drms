# ProyekKas 0.3.4

- Pengajuan: Staff hanya bisa mengajukan untuk dirinya sendiri. Di kolom "Diajukan oleh" hanya nama Anda yang bisa dipilih; pengajuan untuk orang lain dibuat oleh PM, Admin atau Finance. Draft lama yang mencantumkan orang lain menampilkan pesan yang jelas saat diajukan — hapus nama lain lalu ajukan lagi.
- Nota: nota yang sudah divalidasi Finance (status "Valid") terkunci — ikon hapus tidak tampil lagi. Bila server menolak penghapusan, pesan "Nota sudah divalidasi Finance" ditampilkan dan daftar nota dimuat ulang.
- Nota: tanggal nota tetap tidak bisa dipilih setelah hari ini. Bila server menolak nota bertanggal di masa depan, pesannya ditampilkan ("Tanggal nota tidak boleh di masa depan").
- Pesan penolakan dari server kini ditampilkan apa adanya (mis. "Nota sudah divalidasi Finance…", "Staff hanya dapat mengajukan untuk dirinya sendiri…"), bukan lagi pesan umum "Data sudah berubah" / "Anda tidak berhak".
- PM: notifikasi pengajuan tim (diajukan, ditolak, ditransfer, LPJ perlu revisi, selesai) untuk project yang Anda pegang membuka detail pengajuan seperti notifikasi lain.
