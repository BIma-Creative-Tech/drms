# ProyekKas 0.3.0

- Satu akun kini bisa dipakai untuk beberapa PT. Bila Anda punya akses ke lebih dari satu PT, pilih PT di Beranda atau pilih "Semua PT saya".
- Pengajuan, laporan progress, dan absensi selalu tercatat di PT yang dipilih. Saat membuat data baru, aplikasi menanyakan "Untuk PT mana?" bila perlu.
- Data yang belum terkirim dari versi sebelumnya tetap aman. Akun dengan satu PT: data otomatis dikirim ke PT tersebut. Akun dengan beberapa PT: pilih PT untuk data offline tersebut terlebih dahulu.
- Verifikasi 2 langkah (2FA) kini opsional untuk setiap akun: aktifkan atau matikan sendiri di web ProyekKas, menu profil → Keamanan akun.
- Bila 2FA aktif di akun Anda, isi kolom "Kode autentikator" (6 angka dari aplikasi autentikator di HP) saat masuk. Kolom ini muncul setelah percobaan masuk pertama ditolak.
- Akun tanpa 2FA masuk seperti biasa dengan email dan kata sandi.
- Pesan salah masuk lebih jelas, termasuk peringatan bahwa terlalu sering salah dapat mengunci akun sementara.
- Beranda menampilkan "Versi baru tersedia"; ketuk untuk melihat "Yang baru di versi …" dan tautan unduhnya.
