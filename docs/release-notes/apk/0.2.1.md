# ProyekKas 0.2.1

- Verifikasi 2 langkah (2FA) kini opsional untuk setiap akun: aktifkan atau matikan sendiri di web ProyekKas, menu profil → Keamanan akun.
- Bila 2FA aktif di akun Anda, isi kolom "Kode autentikator" (6 angka dari aplikasi autentikator di HP) saat masuk. Kolom ini muncul setelah percobaan masuk pertama ditolak.
- Akun tanpa 2FA masuk seperti biasa dengan email dan kata sandi, tidak ada yang berubah.
- Pesan salah masuk lebih jelas, termasuk peringatan bahwa terlalu sering salah dapat mengunci akun sementara.
- Beranda menampilkan "Versi baru tersedia"; ketuk untuk melihat "Yang baru di versi …" dan tautan unduhnya.
