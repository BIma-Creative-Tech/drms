# RR Teams 0.4.1

- Alur persetujuan pengajuan biaya baru: **Staff → PM project → Direktur → Finance transfer**. Finance tidak lagi memberi approval, hanya mentransfer (dan tetap memverifikasi nota Reimburse).
- **PM project** kini melihat menu **Persetujuan** di Beranda. Pengajuan project Anda yang menunggu tampil sebagai "Persetujuan PM". Tombolnya "Setujui" atau "Tolak" (alasan wajib). Setelah PM menyetujui, pengajuan diteruskan ke Direktur.
- **Direktur** melihat langkahnya sebagai "Persetujuan Direktur". Setelah Direktur menyetujui, pengajuan diteruskan ke Finance untuk transfer.
- Status dan riwayat memakai label baru: "Menunggu persetujuan PM" dan "Menunggu persetujuan Direktur".
- Pengajuan untuk Direktur yang dibuat oleh PM diberi catatan "Pengajuan Direktur — diajukan oleh PM (kebijakan owner 2026-10-10)".
- Pengajuan yang sudah diajukan sebelum aturan baru tetap memakai alur lama (Direktur lalu Finance), dengan label lama.
- Termasuk semua perubahan versi 0.4.0 (versi 0.4.0 belum pernah dirilis; keduanya dirilis bersama server RR Teams 0.7.0).
- Catatan: APK versi lama juga sudah menampilkan tombol Setujui/Tolak kepada PM (tombol diatur server), tetapi masih dengan label "Direktur". Pasang 0.4.1 agar label sesuai.
- Butuh server RR Teams dengan alur "PM project lalu Direktur" dan aturan approval yang sudah diubah Admin.
