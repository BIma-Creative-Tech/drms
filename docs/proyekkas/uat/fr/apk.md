# APK 0.4.0 — Laporan Lapangan (Staff/mekanik, PM, Finance)

Aplikasi Android **RR Teams 0.4.0** (varian staging) di minimal 2 HP. **HP-1** = Mekanik Uji, **HP-2** = Staff Uji Dua
(dan untuk FR-A-20 Finance Uji). Menu: **Beranda → Laporan Lapangan** → tab **Buat laporan** / **Riwayat saya**.
Tanggal (H, H1–H4) mengikuti `README.md`. Foto: kertas bertulisan "HM UJI 1008", "SJ UJI" dsb. — jangan memotret
dokumen atau orang sungguhan.

Mode offline = **mode pesawat** (Wi-Fi dan data mati). Setelah kembali online tunggu ± 1 menit atau buka **Riwayat
saya** sampai status berubah.
