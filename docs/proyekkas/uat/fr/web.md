# Web — Laporan Lapangan (Direktur, PM, Staff/mekanik, Finance, Admin)

Panel web staging, PT **UJI** dipilih. Menu: **Proyek → Laporan lapangan** → **Unit & kontrak**
(`/admin/unit-kontrak`), **Laporan servis** (`/admin/laporan-servis`), **Rekap aftersales** (`/admin/aftersales`),
**Aktivitas aftersales** (`/admin/aftersales/aktivitas`); timeline project di **Proyek → Progress → Progress project**
→ project → tab **Timeline** (`/admin/progress/project/<id>?tab=timeline`).

Data dan tanggal (H, H1–H4, HP) mengikuti `README.md`. Angka EX-01 dari APK: H1 1.000→1.008 (kerja 8, standby 1),
H2 1.008→1.015 (kerja 7, breakdown 4), H3 1.015→1.023 (kerja 8, standby 2), H4 1.020→1.028 (kerja 8).

**Perhatian T-01 (README §Temuan pra-UAT):** isian angka di form/dialog web menampilkan HM ≥ 1.000 dengan titik ribuan
("1.023") tetapi membacanya sebagai desimal. Pada skenario bertanda **[T-01]**, periksa angka HM **sesudah** simpan.
Bila HM berubah sendiri / muncul "Angka tidak valid" pada isian yang tidak Anda ubah → tulis **FAIL T-01**, lalu ketik
ulang angka **tanpa titik** (mis. `1023`) agar skenario berikutnya bisa lanjut.
