# 00 — Persiapan data uji Laporan Lapangan (STAGING)

Dikerjakan fasilitator bersama **Admin** (Admin grup + Admin PT UJI) dan **Direktur** di **staging**
(`https://drms-kas.staging.bimacreative.tech`), **sebelum** sesi UAT. Semua nama, perusahaan, nomor dokumen, dan foto
**fiktif** (lihat `README.md` §Akun uji dan §Data uji). Jangan memakai data DRMS yang asli.

Menu yang disebut adalah menu panel web (`/admin`). Penanda tanggal (lihat `README.md` §Tanggal):
**HP** = hari persiapan (≥ 1 hari sebelum sesi), **H** = hari sesi, **H1/H2/H3** = H−3/H−2/H−1.

## Catatan fasilitator

- **Urutan penting:** FR-P-03 (cek flag OFF) harus dijalankan **sebelum** FR-P-12 (flag ON).
- Kontrak K-001 dimulai tanggal 1 bulan berjalan agar estimasi bulan ini memakai minimum **penuh** 200 jam
  (minimum diprorata bila kontrak tidak sebulan penuh).
- Bila PT UJI dipakai lagi untuk sesi ulang, laporan lapangan **tidak bisa dihapus** (by design). Pakai unit/kode
  baru (mis. EX-11, PO-0922) atau PT uji baru.
- Setelah UAT: nonaktifkan akun uji, akses PT, dan PT UJI (dengan alasan) — tidak ada data yang dihapus.
