# Web — Direktur

Akun: **Direktur** (`owner.uji@proyekkas.test`, peran teknis `pk-owner`). Direktur memberi **"Diketahui" = persetujuan
Direktur** (langkah pertama), mengelola project & tahapan, menyetujui addendum, membuka kembali tutup buku, dan melihat
seluruh dashboard/laporan. Direktur **tidak** membuat pengajuan biaya dan tidak mencatat kas (hanya membaca).
