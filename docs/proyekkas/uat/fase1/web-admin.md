# Web — Admin

Akun: **Admin** (`admin.uji@proyekkas.test`). Admin mengelola user, master data, penomoran, aturan approval, setting
perusahaan, perangkat, jadwal absensi; boleh membuat pengajuan atas nama pemohon. Admin **tidak** memutuskan
pengajuan dan tidak melihat Kas.
