# Web — Finance

Akun: **Finance** (`finance.uji@proyekkas.test`). Finance memberi **Approval** (setelah Direktur), memverifikasi nota
Reimburse, mencatat transfer, memverifikasi LPJ, mengelola kas dan tutup buku. Menu **Alur kerja**: Persetujuan,
Antrian Transfer, Verifikasi LPJ, Kas, Tutup buku, Progress project, Laporan progress, Addendum RAB, Laporan,
Absensi, Audit Log, + Buat pengajuan, Profil & tanda tangan.
